PulseTime — Every Second Counts

PulseTime is a responsive stopwatch web application developed for Task 02 of the SkillCraft Technology Web Development Internship.

It features a clean interface, emerald-green accents, accurate time tracking, lap recording, and a responsive layout for desktop and mobile screens.

Features

- **Start, Pause & Resume:** Control the stopwatch without losing elapsed time.
- **Lap Tracking:** Record lap times and total elapsed times.
- **Lap Statistics:** View total laps, best lap, average lap, and total time.
- **Reset Controls:** Reset the stopwatch or clear lap history.
- **Keyboard Shortcuts:** Use Space to start, pause, or resume; L to record a lap; R to reset; and Esc to clear lap history.
- **Light & Dark Themes:** Switch between display themes.
- **Responsive Design:** Use the application on desktop and mobile screens.

Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts

How to Run Locally

1. Download the repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Start using the stopwatch.
